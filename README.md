# ComicCraft - AI Based Comic Creator

ComicCraft is an AI based web application which generates comic stories automatically using Google Gemini AI.

## Aim of the Project
To help students and story writers to create comics easily without drawing skills.

## Features
- Generate comic story from simple idea
- AI generated dialogues and scenes
- User friendly interface
- Save and Edit story option

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python
- AI Model: Google Gemini Pro API
- Version Control: GitHub

## How it Works
1. User enters story idea
2. System sends prompt to Gemini AI
3. AI generates story with dialogues
4. Output displayed to user
